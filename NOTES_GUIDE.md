# How to add a note

You do not need to edit the website design.

1. Duplicate `_notes/example-note.md`.
2. Rename the copy using a short name, such as `_notes/why-credit-markets-matter.md`.
3. Change the title, date, and description at the top.
4. Write below the second `---` using Markdown.
5. Change `published: false` to `published: true` when it is ready.
6. Commit and push the new file to GitHub. It will appear automatically on the Notes page.

Keep `_notes/example-note.md` as your reusable template.
